# إصلاح 404 لمحرك مشروع Lovable

الحالة: طُبقت الحزمة الفعلية في Lovable بالتحديث `0534539568b6818e52ebe072ca780dc6afe9b5e1`، لكن iframe يستخدم مسار مجلد يعيد 404 في Vite. أوقف Lovable طلب إصلاحه لأن رصيد مساحة العمل نفد؛ لذلك هذا الإصلاح **لم يطبق بعد داخل Lovable**.

التعديل الأدنى في `src/components/villa-generator.tsx`، والاختبار المقابل:

```
/villa-engine/generate/?embedded=1
```

يصبح:

```
/villa-engine/generate/index.html?embedded=1
```

اختبرنا السببين على Vite نفسه: الأول 404، والثاني HTML المحرك الحقيقي مع تشغيل Python وتوليد L/U/متدرج وتنزيل PDF وDXF AC1024 وJSON على الحاسوب وعرض الهاتف، مع إيقاف وإعادة Worker وحجب التصدير بعد التعديل.

بعد ربط مشروع Lovable بـGitHub وتنزيل المستودع، يمكن تطبيق التعديل مع حفظ بقية التغييرات:

```
python fix_engine_path.py /path/to/lovable-project
```

يتحقق السكربت من المصدر قبل الكتابة، ولا يحذف أو يستبدل الملفات الأخرى. ثم شغّل اختبارات المشروع والبناء، وادفع الالتزام إلى الفرع المتصل بـLovable دون force push. لا حاجة إلى اشتراك أو API إضافي لتشغيل المحرك؛ ملفات Python/Pyodide والتراخيص موجودة بالفعل في المشروع.

البديل المجاني لإكمال العمل من هذه الجلسة: افتح المشروع ثم Settings → GitHub → Connect project، وأرسل رابط المستودع الذي ينشئه أو يربطه Lovable. رابط lovable.dev يفتح المحرر ولا يمنح دفع Git إلى مصدره.
