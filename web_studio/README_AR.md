# الاستوديو المحدّث للاستضافة الثابتة

واجهة الاستوديو نفسها تعمل مع خدمة backend/design/service.py داخل Python/WebAssembly في عامل متصفح، دون خادم FastAPI للحسابات. محول HTTP في api.py يستخدم الخدمة نفسها. لا يتغير محرك التوزيع أو الأثاث أو قواعد منع تصدير الرسم.

لإعادة البناء:

```bash
python -m web_studio.build --output /path/to/site/dist/studio
```

يحتاج البناء تنزيل الاعتماديات المحددة في mobile_probe/build_bundle.py. عند التشغيل، تحمل الملفات والخطوط من أصول الموقع نفسه. تصدر الخدمة SVG وPDF وDXF 2010 وJSON. تُحفظ المخرجات محليًا في CacheStorage عند توفره، مع نسخة ذاكرة للجلسة. لا تُرفع مسودات المستخدم إلى خادم حسابات. قد يمسح المتصفح تخزينه؛ تنزيل الملفات يظل نسخة الاحتفاظ الخارجية.

تُحفظ روابط آخر 18 مراجعة في localStorage، ويتقيد مخزن الملفات بـ144 ملفًا. تختلف أرقام هذا الاستوديو ومسوداته عن سجل المحرك السابق؛ لا تُعدّل السجلات السابقة أو يُنقل جدولها تلقائيًا إلى ملف المحفد المعتمد.

فُحصت ثلاث عائلات والأدوار والموقع وتنزيل PDF/DXF/JSON واستعادة السجل بعد إعادة تحميل حقيقية، وحالة تعديل المدخلات، وأربع غرف أبناء، وإيقاف رسم طلب غرفتين غير كافٍ، ومعاينة XLSX غير معتمد، والهاتف بعرض 390 بكسل. الفحوص الهندسية 35 جزئية لكل بديل افتراضي، مع 24 ناجحًا و11 معلقًا؛ ليست شهادة تنفيذ.
