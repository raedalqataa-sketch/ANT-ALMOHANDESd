# ربط واجهة العميل بالمحركات

الواجهة تعرض: المرجعي، البحث المعماري المحلي الموجّه بالمرجعيات، وGemini الذي يقترح JSON محدودًا ثم يمر عبر نفس البناء والتحقق الهندسي. لا يحمل المتصفح المفتاح ولا يتصل مباشرة بـGoogle.

الخادم: GET /api/client/gemini/status يميز الإعداد والاتصال. GET /api/client/gemini/connection يسرد النماذج دون توليد. POST /api/client/gemini/propose يتطلب تسجيل دخول ChatGPT ونفس الأصل والموافقة الصريحة.

متغيرات Sites: GEMINI_API_KEY سر؛ GEMINI_MODEL نموذج Flash متاح ومؤكد المجانية للحساب؛ GEMINI_FREE_TIER_CONFIRMED=true تأكيد المالك وليس تدقيقًا مستقلًا للفوترة. لا يُستنتج السعر من اسم النموذج. لا يمكن قراءة سر GitHub عبر API. لا يُصدر السر في الآثار.

عند غياب الإعداد يظهر التعذر؛ لا استبدال بمخرجات محلية تُنسب إلى Gemini. لا توجد إعادة طلب API تلقائية؛ طلب واحد، حتى ستة خيارات. التكلفة الفعلية غير متاحة عند عدم تقريرها من Google.

تعذر توفير ملفات Vinext وأدوات بناء Sites المعبأة، لذا تُحفظ أصول التطبيق الحالي ويستخدم الأثر واجهة Worker ESM القياسية وASSETS. يجب التحقق محليًا ومن الاستضافة قبل إعلان الخدمة.

المحددات: تخفيف تكرار الطلب في ذاكرة الخادم ليس حصة محاسبية موزعة. النشر التجاري الواسع يحتاج حصصًا دائمة وصلاحيات استخدام. PENDING/REVIEW ليست موافقة على الكود أو البلدية. لا مفاتيح أو اتصالات حية في اختبارات المحاكاة.
