# مختبر اقتراحات Gemini وOpenRouter — ANT-AI-AUTO-KEYS-002

هذه إضافة تجريبية مستقلة على الفرع `feature/ai-auto-keys-002`. لا تستوردها مسارات
التوليد الإنتاجية ولا تغيّر المحرك أو قواعد القبول أو مصدر PDF وDXF. لا يوجد نشر.

## ما ينفذ فعلًا

`architect_planner.propose` يبني البرنامج والارتدادات كما هو. يرسل المختبر الأبعاد
والجهات والبرنامج فقط، دون ملاحظات المالك أو أسماء الموقع، إلى محول Gemini أو
OpenRouter. المخرجات JSON محصورة في 3–6 إعدادات بحث: العائلة الهندسية، ترتيب
الوظائف، موضع الدرج، واستراتيجية الضيوف. يحوّلها `general_engine.generate_general`
إلى النموذج الحالي بالغرف والجدران والفتحات والأثاث، وتعمل فحوص V4 والدستور الجزئي
والتنوع الحالي. لا يكتب النموذج شيفرة ولا حدودًا نظامية ولا إحداثيات غير مفحوصة.

هذا **مساعد للبحث داخل المكتبة الهندسية الحالية**، وليس محركًا عصبيًا حرًا يبتكر
أي كتلة خارجها. تغيير العلاقات يستدعي توزيعًا هندسيًا فعليًا؛ الأسماء وحدها لا تكفي
للتنوع. يختار CP-SAT حتى ثلاثة حلول مختلفة وفق المقياس الحالي، ويعلن العدد الفعلي
إن تعذر استكمالها. يحجب المختبر أيضًا الفجوات المكتشفة بأداة التشخيص الحالية، دون
تعديل قواعد القبول في المحرك الإنتاجي. الكشف المحلي بمقياس 0.5م ليس شهادة خلو
شاملة لكل فراغ محتمل أو ارتداد خارجي واسع.

الهجين يستخدم مزودًا أوليًا، ثم يبني المحرك الهندسة ويفحصها. يتلقى المراجع
الثاني الاختياري مقاييس البدائل الفعلية ونتائج الفحوص ليقترح خطة بحث بديلة،
ويعيد المحرك فحص أي هندسة جديدة. تصحيحان كحد أقصى، والافتراضي تصحيح واحد. المراجع لا يتلقى
تقديرات هندسية مختلقة ولا يملك صلاحية قبول المسقط. العودة للمحرك اختيار صريح
ومعلن في النتيجة. كل النتائج مسودات للمراجعة، لا اعتماد تنفيذي ولا إثبات مطابقة
كاملة للكود أو الخدمات أو الخصوصية البصرية.

## التشغيل المحلي

من جذر الفرع وباستخدام بيئة Python التي تستوفي `requirements.txt`:

```bash
export ANT_AI_LAB_ENABLED=true
python -m backend.design.ai_lab.app
```

افتح `http://127.0.0.1:8002/`. الواجهة عربية وتدعم الهاتف، وتعطل نفسها افتراضيًا.
الخادم مربوط بواجهة loopback ويمنع الأصول الخارجية وطلبات التنفيذ غير الصريحة.
لا تغيّر الربط إلى عنوان عام؛ لا توجد طبقة مستخدمين أو حصص متعددة المستخدمين.
تنفذ تجربة واحدة في الوقت نفسه، وحتى عشر تجارب لكل تشغيل. تُحفظ النتائج في
مجلد النظام المؤقت `ant-ai-lab`، ولا تعني الجلسات المؤقتة نظام تخزين إنتاجي دائمًا.
لا يحتاج خيار المحرك الحالي إلى مفاتيح. استعمال المزود يتطلب موافقة إرسال
الأبعاد والبرنامج واختيار معرّف نموذج رسمي. لا توجد حقول لإدخال الأسرار بالواجهة.

```bash
python -m backend.design.ai_lab.credentials discover
```

يُظهر وجود الأسماء فقط، دون القيم. المفاتيح تقرأ من متغيرات الخادم:
`GEMINI_API_KEY`، `OPENROUTER_API_KEY`؛ النموذجان الافتراضيان اختياريًا من
`GEMINI_MODEL` و`OPENROUTER_MODEL`. لا يوجد معرّف نموذج مفروض أو مفتاح في المتصفح.

## اعتماد الحساب وإنشاء المفاتيح رسميًا

لا يمكن إنشاء اعتماد لحساب لم يسجل صاحبه الدخول. لا توجد في البيئة الحالية
هوية Google مفوّضة أو مفتاح إدارة OpenRouter أو أسرار لهذين المزودين.
لا يقرأ المختبر مخزن المتصفح أو ملفات اعتماد غير مرتبطة.

### Google

المسار الرسمي الأقصر للحساب: [Google AI Studio](https://aistudio.google.com/api-keys).
يدعم Google Cloud الإنشاء البرمجي عبر API Keys API بمصادقة Google وصلاحيات المشروع
المناسبة، ومنها إنشاء/قراءة المفاتيح. عند توفر جلسة `gcloud` المعتمدة ورقم المشروع:

```bash
mkdir -m 700 -p "$HOME/.config/ant-ai-lab"
python -m backend.design.ai_lab.credentials gemini \
  --project-number YOUR_AUTHORIZED_PROJECT_NUMBER \
  --destination "$HOME/.config/ant-ai-lab/providers.env"
```

يعيد استخدام متغير موجود، أو المفتاح المسمى للمهمة إذا كانت قيوده صحيحة؛ وإلا
ينشئ مفتاحًا مقيدًا بـ`generativelanguage.googleapis.com` عبر REST الرسمي.
لا يفعل الفوترة أو خدمة معطلة تلقائيًا. إذا طلب Google تسجيل الدخول أو تفعيل API
أو صلاحية IAM فيجب أن ينفذ صاحب الحساب ذلك رسميًا. لا تمنح صلاحيات أوسع بلا حاجة.
المفتاح التقليدي ليس هوية IAM كاملة؛ قيد الخدمة يقلل نطاق استعماله.

قبل طلب توليد على Gemini، يتحقق صاحب الحساب أن المشروع **غير مفوتر** وأن النموذج
المختار متاح بطبقة مجانية ومنطقته مدعومة، ثم يضبط
`GEMINI_FREE_TIER_CONFIRMED=true` على الخادم. هذا إقرار إعداد، وليس اكتشافًا آليًا
لحالة فوترة المشروع؛ لا يوفر المختبر تحققًا مستقلًا منها. من دون الإقرار يحجب
التوليد. لا تدفع أو تفعل فوترة لإنجاز التجربة. فحص الاتصال هو طلب metadata صغير
ولا يعد نجاحه دليلًا على حصة توليد متاحة. لا يضع المختبر رقم حصة Gemini تخمينيًا.

### OpenRouter

المسار المفضل دون نسخ المفتاح يدويًا هو OAuth PKCE الرسمي، على جهاز صاحب الحساب:

```bash
mkdir -m 700 -p "$HOME/.config/ant-ai-lab"
python -m backend.design.ai_lab.credentials openrouter-oauth \
  --destination "$HOME/.config/ant-ai-lab/providers.env"
```

يفتح المستخدم الرابط الرسمي الذي يطبعه الأمر، ويسجل الدخول ويوافق في OpenRouter.
يستقبل callback محلي على `127.0.0.1:8766` ويستبدل الرمز بالمفتاح على الخادم مع
S256 وstate عشوائي وتحقق مدة وصلاحية واحدة، ولا يسجل رمز callback أو المفتاح.
يجب ضبط حد إنفاق المفتاح على صفر في [إعدادات المفاتيح](https://openrouter.ai/settings/keys)
قبل التجربة؛ لا يزعم مسار OAuth وجود صلاحية إدارة لتعديل الحد تلقائيًا.

إذا كان مفتاح إدارة رسمي مفوض موجودًا في `OPENROUTER_MANAGEMENT_KEY`، يدعم الأمر:

```bash
python -m backend.design.ai_lab.credentials openrouter \
  --destination "$HOME/.config/ant-ai-lab/providers.env"
```

ينشئ مفتاح تطوير بحد `0` دولار ومدة سبعة أيام، ويتجنب تكرار المفتاح المسمى إذا
وجد في القائمة. لا يمكن استرجاع نص مفتاح قديم من قائمة OpenRouter؛ استعد سره
الأصلي أو اطلب تدويرًا صريحًا. لا تنشئ مفتاح إدارة واسعًا إن كان OAuth يكفي.

الحفظ بملف خادم محدد خارج المستودع، بمجلد 0700 وملف 0600 وكتابة ذرية، مع رفض
الروابط الرمزية والحقن بالسطر الجديد. لم تُحفظ مفاتيح حقيقية في هذه المهمة.
لتحميل الملف في جلسة تشغيل خاصة موثوقة:

```bash
set -a
. "$HOME/.config/ant-ai-lab/providers.env"
set +a
```

لا تطبع الملف ولا ترفعه للمحادثة أو Git. شغّل فحص الاتصال من لوحة المختبر بعد
اختيار النموذج، ثم نفذ أقل تجربة لازمة. نجاح إنشاء المفتاح وحفظه منفصل عن نجاح
اختبار اتصال/توليد فعلي. أدوات الإنشاء لا تدعي أن المفتاح اجتاز التوليد بمجرد حفظه.

قبل OpenRouter inference يفحص المحول الأسعار من القائمة الرسمية ويشترط الصفر،
ويمرر `max_price=0` ويعطل routing fallbacks؛ لا تُرسل plugins أو بحث مدفوع.
المعرف `:free` وحده ليس إثبات السعر. الخطأ 402 حظر رصيد، 429 حصة/تقييد، 401
مصادقة، 403 قد يكون تفويضًا/ميزانية/منطقة. لا يعالج أي منها بشراء رصيد.

## القياس وإعادة التجربة

```bash
python -m pytest -q
python -m backend.design.ai_lab.benchmark --mock --output /tmp/ant-ai-mock
python -m backend.design.ai_lab.benchmark --case ye-medium \
  --gemini-model YOUR_CONFIRMED_FREE_MODEL \
  --openrouter-model YOUR_CONFIRMED_FREE_MODEL_ID \
  --output /tmp/ant-ai-live
```

الأمر الحي يحترم نفس حظر الطبقة المدفوعة. بدون نماذج/مفاتيح لا ينفذ طلب inference
ويُسجل `NO_API_RESULT`. `--mock` يستخدم محولات المزودين الفعلية عبر HTTP transport
محاكى، وهندسة حقيقية ومصدر التصدير الحالي؛ يسمى `MOCK_NOT_LIVE` دائمًا. مدخلات
الأراضي من خط الأساس الحالي: السعودية الصغيرة/الركنية/الكبيرة، واليمنية المتوسطة.
المقارنة محدودة بستة خيارات أولية ودون تصحيح إضافي لتقارب ميزانية البحث، وليست
المقارنة مع كامل البحث الإنتاجي الأوسع. اختلاف الزمن مع المحاكاة ليس قياس سرعة
الشبكة ولا دليل جودة النموذج. لا تُستنتج زيادة جودة معمارية قبل تجارب حية ومراجعة
بصرية ومقارنة بنفس المدخلات والميزانية.

تقرير JSON يحتوي أعداد الطلبات والزمن والأسعار المقدرة المتاحة، نتائج الفحوص
ومساحات اتحاد الحركة والغرف والفراغات، والتنوع وسجل التصحيح. PDF وDXF AC1024
للبدائل المجتازة فقط. البيانات المعلقة تبقى معلقة، ولا تطبق السعودية على اليمن.
