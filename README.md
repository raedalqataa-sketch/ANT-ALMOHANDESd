# أنت المهندس — استوديو المحفد V0.4.1

تطبيق ويب عربي محلي لتوليد ومراجعة مساقط فيلا المحفد باستخدام FastAPI وHTML/JavaScript. يعتمد متطلبات Excel: أرض 20×30 م، دوران، أسرة من 9 أفراد. لم يُنشر التطبيق.

المخرجات **مسودات تصميم للمراجعة**. تقدم هذه النسخة ثلاثة تنظيمات مختلفة وفرشًا وفحوص حركة فعلية، مع بنود غير مكتملة ظاهرة في التقرير. لا تمثل أعداد الفحوص درجة جودة معمارية أو اعتمادًا تنفيذيًا.

## تنزيل الملفات

[تنزيل ZIP من GitHub](https://github.com/raedalqataa-sketch/ANT-ALMOHANDESd/archive/refs/heads/main.zip) بعد تسجيل الدخول إلى حسابك؛ أو Code → Download ZIP. تفاصيل الحزمة والتشغيل في [تعليمات التنزيل](DOWNLOAD_AR.md).

## التشغيل

Python 3.11 أو أحدث، ثم:

```bash
./start.sh
```

أو يدويًا:

```bash
python -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

افتح http://localhost:8000. تجربة التعبئة الحرة السابقة في /rectangles. تعمل الواجهة والخدمة من أصل واحد.

## التوليد والمراجعة

- المصدر المعتمد requirements/villa-almahfad.json. استيراد XLSX يعرض القيم للمعاينة والتأكيد؛ النصوص الجديدة لا تتحول تلقائيًا إلى برنامج غرف.
- ثلاثة تنظيمات: **حديقة جانبية وبهو مرتفع**، و**بهو توزيع ومعيشة مترابطة**، و**حوش جانبي وكتلة متدرجة**. تختلف علاقات الأبواب والفراغات والسلم والكتلة، وليس الحجم فقط. البحث ضمن هذه العائلات محدود ولا يضمن أفضل حل معماري.
- غرف صافية وجدران وفتحات وأبواب ذات دوران، وفرش بأبعاد ومناطق استعمال، ومطبخ وتجهيزات صحية، وسلم برحلتين وبسطة، وحديقة وموقف وتراسات علوية متصلة بأبواب فعلية. البهو المرتفع والفرش والكتل مقترحات قابلة للمراجعة.
- عدد غرف الأبناء قابل للاختيار من 2 إلى 4؛ السعة محسوبة من الأسرّة الموضوعة. لا يُزاد العدد المطلوب تلقائيًا لإخفاء عجز السعة. التوزيع الافتراضي يقترح 10 أماكن نوم للأسرة التساعية، وليس توزيعًا معتمدًا لأفرادها.
- فحص اتصال الأبواب والسلم، وفحص حركة ثنائي الأبعاد حول الأثاث والجدران بشبكة 0.20 م وعرض جسم مقترح 0.60 م، وفحص خلوص استعمال مقترح، وعينات رؤية من مدخل العائلة. هذه القيم تصميمية وليست اشتراطات محلية أو تحققًا من الوصول الشامل.
- 35 فحصًا لكل بديل افتراضي: 24 ناجحًا و11 معلقًا وقت المراجعة. لكل فحص معيار ونطاق وأدلة ومعرف مراجعة. أي FAIL يمنع المعاينة وتصدير الرسم، ويبقي JSON التشخيصي متاحًا.
- SVG وPDF بحجم A2 وDXF 2010 بالمتر، بترويسة AC1024 يتم التحقق منها بعد الحفظ، من مشهد هندسي واحد؛ مواد وأثاث وأوزان خطوط وتسميات عربية ومقياس بياني، بخيار الألوان الهادئة أو الأبيض والأسود. أول صفحتين من PDF للدورين، تليهما خلاصة الفحص والافتراضات.
- بصمة هندسية مستقلة عن أسلوب الألوان، ومعرف جديد لكل مراجعة. تعديل المدخلات يوقف روابط التصدير حتى إعادة التوليد. السجل المحلي يفتح الملفات المحفوظة على الخادم.

استُخدمت الصور الخمس لفهم التنظيم والفرش والإخراج؛ لم تُنسخ شعاراتها أو يُفترض أن أبعادها تخص مشروعنا، ولم يُضف مسبح أو دوبلكس. توثيق المقارنة والقيود في [مراجعة V0.4](quality_review/V04_REFERENCE_REVIEW_AR.md)، وفهرس الصور وبصماتها في references/quality_precedents_v04.json.

## تحسين الأثاث في V0.4.1

تحسين العرض فقط مع تثبيت توزيع الغرف والأبواب والأثاث وأبعاده: كنب بتنجيد ووسائد رخوة وخياطات، وأسرّة بلوح رأس مبطن وطبقات مفروشات، وكراسي منحنية وطاولات رخامية متداخلة وخشب ولمسات نحاسية. الرسومات متجهة أصلية، وليست صورًا أو كتلًا تجارية محملة. التفاصيل زخرفية داخل أغلفة الأثاث المقترحة، ولا تغيّر السعة أو مناطق استعمال القطع.

تظهر المنحنيات في SVG وPDF، وتُحوّل في DXF إلى حدود متجهة بتسامح تسطيح مقترح 0.8 ملم، مع الاحتفاظ بالتعبئات. تظل أقواس الأبواب ARC مستقلة عن منحنيات الأثاث. فُحص احتواء الرموز في أغلفتها عند جميع الدورانات المستخدمة. لا تمثل زيادة التفاصيل اعتمادًا بشريًا لذوق الأثاث أو بلوغ المستوى النهائي المطلوب.

[مقارنة قبل وبعد](quality_review/furniture_review/furniture-before-after.pdf)، و[المسقط المحدّث](quality_review/furniture_review/villa-furniture-review.pdf)، و[DXF 2010](quality_review/furniture_review/villa-furniture-review.dxf). لإعادة توليد أمثلة المراجعة: `python -m quality_review.export_furniture_review`.

## الحدود الحالية

لا يوجد رفع مساحي أو اشتراطات وارتدادات موثقة أو جهات فتح متحققة. أبعاد المبنى والغرف والسلم والفرش والتراسات وسماكات الجدران **مقترحات**. الشمال بحسب المصدر، وليس قياسًا موقعيًا. الموقف غلاف ثابت 2.8×5.4 م، ولا يثبت مناورة السيارة أو مناسبة البوابة والشارع.

فحوص الحركة والخلوص وعينات الرؤية جزئية؛ لا تثبت كل أوضاع الاستخدام أو فتح الأبواب أو رؤية شخص من كل المداخل. كفاية الإضاءة والتهوية وقانونية الفتح، والخلوص الرأسي للسلم، والإنشاء والخدمات وسلاسل الأبعاد التنفيذية غير مكتملة. تظل قرارات المصعد والخادمة ومدخل الخدمة معلقة، وبعض الفراغات المفضلة مؤجلة صراحة. المؤن والمستودع فراغ مشترك مقترح، ولا يُحسبان فراغين مستقلين. لا تُنمذج واجهات أو رندرات أو حسابات إنشائية.

المرجع constitution/references/floor_plan_rules_v1.json محفوظ دون تغيير. لقطة SITE_V9 التاريخية فيه لا تصف جاهزية هذا التطبيق. لا يدّعي الإصدار تنفيذ الأنماط المرجعية الـ18 أو اعتماد A5. فهرس التنفيذ الحالي constitution/runtime_coverage_v04.json يوضح نطاق الفحوص المحدود.

## التحقق

```bash
python -m pytest -q
node --check frontend/app.js
node --check frontend/studio.js
```

نجحت 39 حالة اختبار، تشمل أخطاء متعمدة في الهندسة والمرجع والسعة وخلوص الاستعمال، وسد مسار بالأثاث رغم اتصال الأبواب، وإزالة فرش غرفة إضافية رغم كفاية مجموع الأسرّة، وإزالة اتصال السلم مع بقاء باب التراس. فُحصت الواجهة بـChromium على سطح المكتب والهاتف، والبدائل والسجل ومنع تصدير مراجعة قديمة أو فاشلة، ومعاينة Excel تجريبي ومنع اعتماده تلقائيًا. روجعت لوحات PDF وSVG بصريًا. يُعاد فتح DXF بمكتبة ezdxf؛ لم يُختبر في AutoCAD مستقل أو على جهاز Android فعلي.

اختبار تعبئة المستطيلات الاصطناعية السابق موثق في quality_review/V03_IMPLEMENTATION_AR.md، ولا يقيس جودة المساقط المعمارية الجديدة.

## API

- GET /api/v2/project: المتطلبات وفهرس مصدر القواعد ونطاق التنفيذ.
- POST /api/v2/import-excel: معاينة XLSX العربي.
- POST /api/v2/design: توليد وفحص ومخرجات مراجعات جديدة.
- GET /api/files/{filename}: تنزيل ملف مراجعة.
- /api/generate و/api/import-excel: تجربة التعبئة الحرة السابقة.

```json
{"layout_family":"reference_search","bedroom_count":3,"output_style":"presentation","candidate_count":3,"floor_height":3.2,"double_height":null}
```

يمكن اختيار garden_gallery أو social_hub أو open_court، وmonochrome للإخراج الأسود والأبيض. double_height يخص تنظيم الحديقة؛ null يتبع المقترح الافتراضي. تُقبل أبعاد مبنى مخصصة بعرض 12.5–17.5 م وعمق 18.5–23 م، وارتفاع دور 2.8–4 م. بعض القيم تفشل الفحص؛ لا يضمن النطاق العددي صلاحية الحل. confirmed_opening_faces إفادة مدخلات وليست شهادة قانونية. legacy يعيد مولد V0.3 للمقارنة.

## Docker والتخزين

```bash
docker build -t ant-almohandes .
docker run --rm -p 8000:8000 ant-almohandes
```

يمكن تحديد PORT. أُعد Dockerfile لنسخ المصادر والخطوط والقواعد والمراجع؛ لم يُبن أو يُختبر كحاوية في هذه المراجعة.

outputs/ ملفات محلية على الخادم؛ حذفها يعطل روابط السجل. سجل localStorage لا يغني عن تنزيل الملفات. لا توجد حسابات متعددة أو تحكم وصول أو تنظيف تلقائي؛ هذا إصدار عمل محلي.

الخطوط محلية. تراخيص Noto وDejaVu في frontend/FONT-LICENSE.txt وfrontend/LATIN-FONT-LICENSE.txt. PlanFont.ttf مشتق محدود المحارف من DejaVu Sans، أعيدت تسميته داخليًا ANTPlan، لتضمين العربية واللاتينية في اللوحات دون اتصال خارجي.

## تجربة محرك محلي لأندرويد

نجح اختبار المحرك في WebAssembly داخل Chromium مع تعطيل الشبكة أثناء التوليد والتصدير. مشروع غلاف APK تجريبي وتفاصيل القياس والقيود في [تقرير جدوى أندرويد](mobile_probe/README_AR.md). هذا ليس اختبارًا على هاتف أو تحويلًا كاملًا للاستوديو؛ مثال الأثاث واستوديو الويب الحالي لا يتغيران.
