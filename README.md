# أنت المهندس — استوديو المخططات V0.2

تطبيق ويب عربي باتجاه RTL مبني على النموذج المرفق V0.1 باستخدام FastAPI وJavaScript. الواجهة والخدمة تعملان من أصل واحد.

## التشغيل

يتطلب Python 3.11 أو أحدث. على Linux وmacOS:

```bash
./start.sh
```

أو على أي نظام:

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows بدلاً من السطر السابق:
# .venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

افتح http://localhost:8000. لا تفتح ملف HTML مباشرة، لأنه يعتمد على خدمة التطبيق.

## تشغيل Docker

```bash
docker build -t ant-almohandes .
docker run --rm -p 8000:8000 ant-almohandes
```

يمكن تحديد منفذ خدمة الاستضافة عبر متغير `PORT`. ملفات التصدير داخل الحاوية مؤقتة ما لم تربط تخزينًا دائمًا بـ `/app/outputs`. إعداد Docker لا ينشر التطبيق أو ينشئ استضافة تلقائيًا. قبل إتاحة التطبيق للعامة، أكمل متطلبات الصلاحيات وحدود التشغيل الموضحة أدناه.

## الميزات

- واجهة عربية متجاوبة للهاتف والحاسوب، بخط عربي محلي يعمل دون خدمة خطوط خارجية.
- إدارة اسم المشروع وأبعاد الأرض والغرف وأنواعها، مع حساب المساحات.
- معاينة SVG تفاعلية، تكبير وملاءمة وعرض بيانات الغرفة عند اختيارها.
- استيراد XLSX وقالب قابل للتنزيل، مع دعم جدول غرف من ثلاثة أو أربعة أعمدة.
- تصدير DXF بالمتر، وPDF يتضمن أسماء الغرف العربية، وتقرير JSON يتضمن المدخلات لفتح المشروع مجددًا.
- حفظ المشاريع محليًا في المتصفح وإعادة فتحها وتنزيلها وحذفها.
- فحص المدخلات وعرض بنود المراجعة المعلّقة وتعطيل المخرجات بعد تغيير المدخلات.
- دليل استخدام داخل التطبيق.

## Excel

- A1=`title`, B1=اسم المشروع.
- A2=`plot_width`, B2=عرض الأرض بالمتر.
- A3=`plot_depth`, B3=عمق الأرض بالمتر.
- الصف 6 عناوين `name,width,depth,kind`.
- الصف 7 وما بعده للغرف. النوع اختياري، وقيمه: living, bedroom, kitchen, bathroom, other.
- حد الرفع 5 ميغابايت. استخدم القالب من التطبيق.

## التخزين وحدود النسخة

المشاريع محفوظة في localStorage لهذا المتصفح والأصل فقط؛ حذف بيانات المتصفح يزيلها. نزّل ملفات JSON لنسخة خارجية. ملفات التصدير في outputs/ على الخادم، ولا توجد حسابات أو صلاحيات متعددة المستخدمين أو تنظيف تلقائي لهذه الملفات. التطبيق مهيأ للتشغيل المحلي؛ لم يُنشر على خدمة عامة. يتطلب النشر العام إعداد صلاحيات وتخزين وحدود تشغيل مناسبة.

المحرك يرتّب مستطيلات في صفوف حسب عمقها. لا يشمل أبوابًا أو نوافذ أو سماكات جدران أو حركة أو خصوصية أو اعتمادًا هندسيًا، وقد يفشل في توزيع يمكن تحقيقه بخوارزمية أخرى. لا توجد خدمات ذكاء اصطناعي أو تصميم معماري آلي متكامل. سهم الاتجاه في الواجهة افتراضي. لم تُضف اشتراطات محلية أو ملفات دستور غير مرفقة.

لا تستخدم المخرجات للتنفيذ أو التسليم المهني دون تطوير ومراجعة هندسية. ملف DXF يحفظ النصوص Unicode؛ قد تحتاج إلى اختيار خط يدعم العربية في برنامج CAD.
