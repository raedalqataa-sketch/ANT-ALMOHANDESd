# أنت المهندس — استوديو المحفد V0.3

تطبيق ويب عربي محلي لتطوير ومراجعة مساقط فيلا المحفد، مع FastAPI وواجهة HTML/JavaScript. مصدر المشروع المعتمد هو Excel: أرض 20×30 م، دوران، أسرة من 9 أفراد. حزمة القواعد الأصلية محفوظة دون تعديل في constitution/references/.

**الحالة: مسودات تصميم غير معتمدة.** لا يدّعي الإصدار توليد مخططات تنفيذية أو تنفيذ كل القواعد الواردة في الحزمة. الموقع لم يُنشر.

## التشغيل

يتطلب Python 3.11 أو أحدث. على Linux وmacOS:

```bash
./start.sh
```

أو:

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows بدلاً من السطر السابق:
# .venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

افتح http://localhost:8000 لاستوديو المحفد. تجربة المستطيلات الحرة السابقة في http://localhost:8000/rectangles. الواجهة والخدمة تعملان من أصل واحد؛ لا تفتح HTML مباشرة.

## ما ينفذه الإصدار

- عرض المتطلبات الإلزامية والتفضيلات والتعارضات والبيانات المجهولة من ملف المشروع requirements/villa-almahfad.json.
- قراءة Excel العربي ومعاينة ربط القيم، بما فيها الأرقام العربية. يُعرف ملف المحفد المعتمد ببصمته؛ النصوص والبرامج المعدلة تحتاج ربطًا ومراجعة ولا تُحوّل تلقائيًا إلى برنامج غرف.
- ثلاثة بدائل ضمن **عائلة توزيع واحدة محدودة**: جناحان وممر عائلي مركزي ومدخل مستقل للرجال، مع أرضي وأول. يتغير حجم المبنى، لا البرنامج الوظيفي تلقائيًا.
- غرف صافية وجدران بسماكات مقترحة، وأبواب مرتبطة بالجدران وفتحات فعلية، ونوافذ خارجية، وفرش وتجهيزات وأسرّة، وسلم برحلتين وقوائم ونوايم وبسطة وارتفاع دور مقترح.
- 29 فحصًا على النموذج: 18 ناجحًا و11 معلقًا في الإعداد الافتراضي وقت الفحص. النتائج تعتمد على المدخلات؛ ليست نسبة امتثال أو درجة جودة شاملة. كل نتيجة تحمل القاعدة والمراجعة والمعيار والأدلة والنطاق.
- كشف التداخل والخروج عن الحدود والروابط المكسورة ونقص التجهيزات والتعارضات المحافظة لدوران الأبواب، وتتبع الوصول عبر الأبواب والسلم ومسار ضيوف الرجال إلى خدماتهم.
- عرض حالة PENDING للبيانات أو الفحوص غير المكتملة. فشل أي فحص منفذ يمنع PDF/DXF والمعاينة للرسم، مع إتاحة JSON التشخيصي.
- SVG وPDF للدورين وDXF بالمتر من مراجعة هندسية واحدة. فجوات الفتحات تقطع مسارات الجدران، والأبواب ممثلة بضلف وأقواس. يُعاد فتح DXF للتدقيق.
- حفظ ملفات كل مراجعة على الخادم بمعرف جديد، وسجل روابط في المتصفح. الحفظ لا يعني الاعتماد. تتوقف روابط التصدير في الواجهة عند تعديل المقترحات حتى إعادة التوليد.
- تحسين تعبئة المستطيلات الحرة باستخدام MaxRects وعدة ترتيبات، دون تدوير تلقائي أو تغيير الأبعاد.

## القيود المعلنة

أبعاد المبنى وسماكات الجدران وارتفاعات الأدوار وأبعاد الأثاث والفتحات **مقترحات تصميمية وليست اشتراطات رسمية**. الفراغ حول المبنى ليس اعتمادًا للارتدادات. عدد غرف الأبناء والسعة المقترحة 12 مكان نوم ليس توزيعًا معتمدًا لأفراد الأسرة التسعة.

لا توجد بيانات رفع مساحي أو ارتدادات موثقة أو جهات فتح مسموحة متحققة. الشمال أعلى الرسم بحسب المصدر دون قياس موقعي. الموقف غلاف 2.5×5 م مقترح؛ لم يُتحقق من مناورة السيارة أو البوابة أو الربط بالشارع. لا تُنمذج واجهات أو رندرات أو حسابات إنشائية.

وجود النافذة لا يثبت كفاية التهوية أو قانونية الفتح. وجود الأثاث وعدم تداخله لا يثبت خلوص الاستعمال. فحص الوصول شبكي، وليس تحليلًا كاملًا لخلوص المشاة أو الوصول الشامل. الخلوص الرأسي للسلم، وخطوط النظر، وتنسيق الخدمات والإنشاء، وسلاسل الأبعاد التنفيذية غير مكتملة. بعض التفضيلات مؤجلة وتظهر في التقرير. المصعد والخادمة ومدخل خدمة المطبخ ما زالت قرارات معلقة.

حزمة القواعد مواصفات مرجعية؛ لقطة SITE_V9 داخلها تخص مصدرها ولا تصف هذا التنفيذ. لا تدّعي النسخة نظام اعتماد A5 أو اعتمادًا هندسيًا أو تنفيذًا لكامل الأنماط الـ18. كل المراجعات الجديدة مسودات، ولا يتوفر مسار لاعتماد أو تعديل نسخة تنفيذية مقفلة.

```bash
python -m pytest -q
```

نجحت 23 حالة اختبار وقت الإصدار، تشمل إفساد الهندسة عمدًا للتأكد من كشف الخطأ ومنع تصدير الرسم. فُحصت الواجهة بمتصفح Chromium على مقاسي سطح المكتب والهاتف، وتمت مراجعة صفحتي PDF بصريًا. لم يُختبر DXF داخل AutoCAD مستقل أو التطبيق على جهاز Android فعلي.

في العينة الاصطناعية ذات البذرة 20261017، حلّ المحرك الجديد 296 من 300 حالة تعبئة ممكنة مقابل 64 سابقًا، دون تداخل أو تغيير أبعاد في الحلول المقبولة. هذا اختبار تعبئة مستطيلات؛ لا يقيس الجودة المعمارية أو نسبة نجاح المشاريع الواقعية. راجع quality_review/V03_IMPLEMENTATION_AR.md.

## API

- GET /api/v2/project: المتطلبات وفهرس مصدر القواعد ونطاق التنفيذ.
- POST /api/v2/import-excel: معاينة ملف XLSX العربي، دون اعتماد نصوص غير معروفة تلقائيًا.
- POST /api/v2/design: توليد البدائل والفحوص وملفات مراجعات جديدة.
- GET /api/files/{filename}: ملفات المراجعات المنشأة على الخادم.
- /api/generate و/api/import-excel: القالب القديم لتجربة غرف ذات أبعاد ثابتة.

مثال توليد:

```json
{"candidate_count":3,"floor_height":3.2}
```

الإعدادات المخصصة تدعم عرض مبنى 14–17 م وعمق 19.2–23 م ضمن عائلة التوزيع، وارتفاع دور 2.8–4 م. بعض التوليفات تفشل فحص السلم وتصدر تقريرًا فقط. confirmed_opening_faces بيان من مقدم الطلب للفحص، وليس شهادة قانونية. لا يسمح باستبدال ملف المتطلبات المعتمد بملف مختلف عبر طلب التوليد.

## Docker

```bash
docker build -t ant-almohandes .
docker run --rm -p 8000:8000 ant-almohandes
```

يمكن تحديد PORT. ملفات outputs/ مؤقتة داخل الحاوية ما لم تربط تخزينًا دائمًا وتمنح المستخدم appuser حق الكتابة إليه. ملف Docker أُعدّ لاستيعاب المتطلبات والقواعد والخطوط؛ لم يُبن أو يُختبر كحاوية في هذه المراجعة.

## التخزين والاستخدام

الملفات محفوظة على خادم العمل المحلي في outputs/؛ حذفها يعطل روابط السجل. سجل المراجعات في localStorage مرتبط بالمتصفح والأصل، ولا يغني عن تنزيل الملفات. لا توجد حسابات متعددة المستخدمين أو تحكم وصول أو تنظيف تلقائي للملفات؛ هذا إصدار عمل محلي. لا تغيّر إتاحته للعامة دون تهيئة هذه الجوانب.
