# تجربة العميل لتوليد المساقط

## قرار التنفيذ

بدأ العمل من `main` عند `9335f58`. راجعت واجهة العميل الحالية وواجهة المحرك العامة ومعالج الربط، وفحصت الفروع المتعلقة بالعميل والبدائل ودورة حياة عامل المتصفح. أبقيت React وTypeScript في المعالج الحالي. تعرض واجهة المحرك المضمّنة ملفاته الأصلية بعد التحقق، عبر القناة الحالية التي تتحقق من النطاق ونافذة المصدر ومعرّف الجلسة. يعمل Python في Pyodide على جهاز العميل. لا يتطلب هذا المسار حسابًا أو نموذجًا مدفوعًا.

| الخاصية | ما يمكن للعميل استخدامه |
| --- | --- |
| المتطلبات | مسار عربي من ثلاث مراحل. حقول رفع المخطط والموقع التفصيلي اختيارية. تظهر تفضيلات مستوى التصميم والأولوية في المراجعة. يمكن الانتقال إلى إدخال تفصيلي من خمس مراحل مع استيراد Excel. |
| التصميم | يرسل المسار المبسط الأرض واحتياجات الأسرة إلى مخطط البرنامج الآلي ثم البحث الهندسي. يستخدم الإدخال التفصيلي محوّل المحرك ومراجعة مدخلاته القائمة. |
| المقارنة | صور مصغرة من مساقط البدائل المجتازة. يسجل الجدول المساحات، الفراغات، المسارات المقاسة والبنود المعلقة من تقرير المحرك. |
| النتائج | تنقل بين الأدوار والموقع المتاح، تكبير، اختيار بديل مؤقت داخل الجلسة، وعودة واضحة لتعديل الطلب وإعادة التوليد. |
| الملفات والفحوص | يعرض عدد البدائل الحقيقي وأسباب التعذر التي يعيدها المحرك. SVG وPDF وDXF تظهر عند توفرها وسماح بوابة الرسم، وJSON عند توفر تقريره. تظل ملفات طلب سابق محجوبة بعد تغييره. |

تظهر القياسات والفحوص تحت أقسام قابلة للفتح. المقترحات مسودات للمراجعة. لم يُغيّر هذا الفرع قواعد قبول الهندسة أو هندسة أي مسقط معتمد. تبقى المدخلات في ذاكرة المتصفح ومسودة مؤقتة في التبويب، وتُنزل الملفات بطلب من العميل. معاينة الملف المرجعي للأرض تتم محليًا.

## إعادة الاختبار والمعاينة

من جذر المستودع، شغّل في بيئة محلية متاحة لـPython وNode 22 أو أحدث:

```sh
npm ci --prefix client_web --ignore-scripts --no-audit --no-fund
mkdir -p /tmp/ant-client-preview/.openai /tmp/ant-client-preview/dist
printf '%s\n' '{"static":{"directory":"dist"}}' > /tmp/ant-client-preview/.openai/hosting.json
cp frontend/index.html /tmp/ant-client-preview/dist/index.html
python -m web_studio.build --output /tmp/ant-client-preview/dist/studio
python -m web_generator.build --output /tmp/ant-client-preview/dist/generate
python -m client_web.build_site --site /tmp/ant-client-preview
python -m http.server 8041 --bind 127.0.0.1 --directory /tmp/ant-client-preview/dist
```

افتح http://127.0.0.1:8041/client/ على الجهاز نفسه. تنزيل الاعتماديات المفتوحة مطلوب في البناء الأول. الحزمة المبنية تعمل على أصل واحد وتخدم ملفات المحرك محليًا.

```sh
python quality_review/client_web/generation_experience.py --out /tmp/ant-generation-qa
node --test tests/*.test.cjs
python -m pytest -q
```

يوثّق الاختبار خمس رحلات ببيانات مختلفة ويتحقق من مسار الرسم والتنزيل الفعلي، ومن حالة التعذر، وعدم إرسال طلبات إلى نطاقات أخرى أثناء التوليد. يحتاج Chromium وPlaywright for Python.

## حدود تحتاج عملاً في المحرك

- نطاق مثبت لهذا المسار هو سكن خاص بدور أو دورين وأرض مستطيلة بعرض 8–60 م وعمق 8–80 م. بعض الطلبات تعيد بديلًا أو اثنين أو تتعذر.
- قراءة صورة أو PDF للأرض تتطلب مراجعة العميل للأبعاد. لا تستنتج بيانات الملكية أو الارتدادات المحلية تلقائيًا.
- ترتيب البدائل والفحوص الحالية أولية. تدقيق شامل للخصوصية البصرية والصوتية والإضاءة والتهوية والكود المحلي، ومعالجة مواقع غير مستطيلة، تحتاج تطويرًا وتحققًا إضافيًا. الارتدادات في اليمن افتراضات تصميمية.
- التوليد الكامل للمباني الاستثمارية والوحدات المستقلة والتعديل الهندسي المتقدم ونماذج 3D وIFC وRevit تحتاج مسارات هندسية معتمدة وفحوصًا خاصة بها.
